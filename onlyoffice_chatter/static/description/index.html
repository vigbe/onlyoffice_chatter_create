ONLYOFFICE Chatter Integration

Create OnlyOffice documents directly from the Chatter of any Odoo record.

Developed by vicbas.com

Key Features

Create Documents

Create DOCX, XLSX, and PPTX files from any Chatter.

Native Attachments

Files are stored as standard ir.attachment — no extra apps needed.

Community Edition

Works with Odoo Community. Does not require Enterprise Documents.

Inside the Chatter

A New button next to the Chatter actions on any record — no separate application.

Multilingual

Available in English, Spanish, French, Russian, Chinese, and Dutch (Belgium).

Free & Open Source

LGPL-3 licensed, built on the official onlyoffice_odoo module.

How It Works

  • 1. Click the "New" button on any Chatter.
  • 2. Choose a format and enter a title.
  • 3. The file is created as a standard attachment on the record and opens in ONLYOFFICE, ready to edit.

Supported Formats

.docx

Word Document

.xlsx

Excel Spreadsheet

.pptx

PowerPoint Presentation

Requirements

  • onlyoffice_odoo module installed and configured
  • ONLYOFFICE Document Server running and accessible
  • Odoo 19.0 Community or Enterprise
