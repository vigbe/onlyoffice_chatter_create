ONLYOFFICE Chatter Integration

A “New” button in the chatter of any record: create a blank document, spreadsheet or presentation and start editing it in ONLYOFFICE — without leaving the record.

Developed by vicbas.com

What it does

Documents from the chatter

On any record, a New button next to the paperclip opens a small dialog: pick docx, xlsx or pptx, name it, done.

Native attachments

The file is created as a normal ir.attachment on the record — no Enterprise Documents app, no separate folder tree, nothing to migrate.

Straight into the editor

Creation drops you directly into the ONLYOFFICE editor tab for that document, ready to type.

How to use it

Prerequisite-first, five steps total:

  1. Prerequisites (read first)
    You need a running ONLYOFFICE Docs server and the open-source onlyoffice_odoo connector (LGPL-3) installed and connected. This module extends that setup — it does not bundle an editor.
  2. Install this module
    It only adds the chatter button and the create flow; existing ONLYOFFICE configuration is untouched.
  3. Open any record
    Leads, tasks, tickets, partners… the chatter's New button appears for every internal user (document creation respects record write access).
  4. Choose format and title
    Document (.docx), Spreadsheet (.xlsx) or Presentation (.pptx), plus the file name.
  5. Create and edit
    The blank file is generated from the connector's template for your language, attached to the record, and opened in the ONLYOFFICE editor.

Supported formats

Format Extension Blank template

Requirements
Odoo 18.0 (Community; Enterprise also works)
Dependencies onlyoffice_odoo connector (open source, LGPL-3)
External services ONLYOFFICE Docs server (self-hosted or cloud)
