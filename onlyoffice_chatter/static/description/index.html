ONLYOFFICE Chatter Integration

New documents, right from the chatter

ONLYOFFICE Chatter Integration adds a New button to the chatter of every record. Pick a format, give it a name, and a blank file is attached to the record and opened in the ONLYOFFICE editor. No Enterprise Documents app required.

Features

What it does

Create from the chatter

A New button next to the paperclip opens a small dialog: choose docx, xlsx or pptx and a name.

Native attachments

The file is a normal ir.attachment on the record. No separate folder tree, nothing to migrate.

Straight into the editor

After creating it, the document opens in the ONLYOFFICE editor, ready to type.

Localized templates

Blank files come from the connector's templates for your language.

Respects permissions

Files are created only on records the user can write.

Lightweight

Only adds the button and the create flow; your ONLYOFFICE setup is untouched.

Getting started

How it works

1
Prerequisites
A running ONLYOFFICE Docs server and the open-source onlyoffice_odoo connector (LGPL-3), installed and connected.
2
Install this module
It extends the connector; it does not bundle an editor.
3
Open any record
Leads, tasks, tickets, partners… the New button appears in the chatter.
4
Create and edit
Choose Document, Spreadsheet or Presentation, name it, and start editing.

Details

Format File
Document .docx — localized blank template
Spreadsheet .xlsx — localized blank template
Presentation .pptx — localized blank template
